# Практика базового Pygame

Пятый урок раздела «Знакомство с Pygame» курса «Разработка игр на Python. Основы» (`python-gamedev-basics`). Установлен в текущую базу: курс 3, раздел 9, урок 99, степы 557–562.

Шесть степов чередуют подготовку и самостоятельные задания:

1. Состояние программы и выбор цифры по KEYDOWN.
2. Цифровое табло из семи прямоугольных сегментов, цифры 0–9.
3. Отсчет кадров через переменную timer, пример с прямоугольником, Clock и tick(60).
4. Автоматический светофор: красный → красный с желтым → зеленый → желтый.
5. Направление через vx и vy, обновление координат вне обработчика событий.
6. Зеленый круг радиусом 20 в окне 800×600: непрерывное движение и повороты по WASD.

Задания перенесены из трех предоставленных документов. `sources.json` сохраняет исходный текст, ссылки и описание адаптации. Дополнены начальные состояния, учебные интервалы светофора, подсказки. Степы используют штатные блоки text, code, callout и image; задания рассчитаны на локальную работу с Pygame, как практика в предыдущих уроках. Готовые решения заданий и автопроверка стандартного вывода ученику не показываются.

## Материалы и анимации

- `content.py` — исходный материал, четыре учебных блока кода, включая одну полную программу таймера.
- `materials.md` — весь урок с локальными ссылками на GIF.
- `lesson.json` — экспорт в формате платформы.
- `render.py` — служебные образцы заданий и воспроизводимая отрисовка GIF настоящим Pygame с SDL dummy. Эти решения в материалы ученика не входят.
- `images/digits.gif` — цифры 0–9, переход 8 → 1 → 0, нажатия и отпускания.
- `images/traffic.gif` — полный цикл светофора с длительностями 2/1/2/1 секунды.
- `images/direction.gif` — движение без удержания клавиш, повороты, пояснение повтора GIF.
- `images.json` — привязки файлов текущей базы, пути и SHA-256.
- `browser-verification.json` — результаты проверки всех шести степов при ширине 1440 и 390 пикселей.

Во всех GIF игровая область снята с поверхности Pygame без масштабирования. Над ней добавлена поясняющая плашка; у табло и светофора также добавлены боковые поля. При генерации исполняются кадры программы с настоящей очередью событий; реальное ожидание в tick(60) отключено. Светофор использует счетчик timer: 120/60/120/60 кадров. У круга сохраняется каждый шестой кадр программы, GIF идет с частотой 10 кадров/с. Каждый файл меньше 110 КБ.

## Проверка

Из корня проекта, Python с Pygame, Pillow и зависимостями приложения:

```bash
.venv/bin/python -m data.pygame_practice.render
.venv/bin/python -m data.pygame_practice.verify
.venv/bin/python -m data.pygame_practice.build --check --export
```

`verify.py` проверяет таймер при уменьшении и сбросе счетчика, все цифры, сохранение выбранной цифры после отпускания, два цикла светофора, все направления WASD, отсутствие остановки при KEYUP, повторные и посторонние клавиши, несколько событий в кадре, очистку следов и закрытие через QUIT. Все 71 демонстрационных кадра сверяются с исполнением образцов: игровая область побайтово и длительности кадров. Это проверка с SDL dummy, без ручного ввода в системное окно.

Схемы шести степов, синтаксис четырех учебных фрагментов и каждый кадр трех GIF проверены. В браузере подтверждены содержание степов через API, отображение кода и таблиц, шесть пунктов навигации, загрузка GIF и отсутствие горизонтального переполнения страницы. Проверены HTTP 200, MIME image/gif и SHA-256 опубликованных файлов. Выбранные кадры GIF и страницы просмотрены визуально. Снимок до импорта подтвердил сохранение всех полей четырех прежних уроков и 45 степов. Повторный импорт сверил содержание без создания дубликатов.

Объяснения сверены с официальной документацией Pygame: [время](https://www.pygame.org/docs/ref/time.html), [клавиши](https://www.pygame.org/docs/ref/key.html), [рисование](https://www.pygame.org/docs/ref/draw.html).

## Загрузка

Для повторной проверки текущей базы скопируй каталог в работающий контейнер и выполни:

```bash
docker compose exec -T app mkdir -p /app/data/pygame_practice
docker compose cp data/pygame_practice/. app:/app/data/pygame_practice/
docker compose exec -T app python -m data.pygame_practice.build --apply --course-id 3
```

В контейнере должны быть доступны `content.py` из `data/pygame_intro`, `data/pygame_drawing`, `data/pygame_movement` и `data/pygame_keyboard`. Остальные файлы прежних уроков для импорта не нужны.

Для другой базы с четырьмя предыдущими уроками скопируй каталог **без images.json** и используй ID ее курса:

```bash
python -m data.pygame_practice.build --apply --course-id <ID курса>
python -m data.pygame_practice.illustrations --apply --lesson-id <ID нового урока>
python -m data.pygame_practice.build --check --export
```

При работе в Docker скопируй созданные `images.json` и `import-result.json` обратно на хост и обнови локальный экспорт. Привязки изображений зависят от базы.

Импортер блокирует строку курса на время транзакции, проверяет slug, раздел и порядок четырех предыдущих уроков. Существующие материалы не переписывает, при отличиях останавливается. Скрипт иллюстраций сверяет урок, регистрирует файлы штатным StorageService, повторно использует загрузки с тем же SHA-256 и удаляет новые файлы при откате транзакции.

Текущая редакция использует только счетчик кадров `timer -= 1` с проверкой `timer == 0`, без get_ticks(). Скорости названы `vx`, `vy`. Удалены блоки «Проверь перед сдачей», указанный текст про KEYUP, заключение о сдаче файла в светофоре и «С чего начать» в задании WASD. Подсказка к светофору вынесена после GIF в самый конец степа.
