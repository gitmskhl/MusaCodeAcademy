# Второй урок разработки игр

В курс 3 `python-gamedev-basics`, раздел 9 «Знакомство с Pygame» добавлен урок 51 «Рисуем круги: координаты и снеговик», порядок 1 (второй после урока 50). Первый степ — 369.

Урок содержит 12 степов: первый рисунок, четыре аргумента `pygame.draw.circle`, координаты, перемещение по осям, центр и радиус, касание левой стенки, правой стенки, правой и нижней одновременно, полный выход за экран, порядок рисования, самостоятельный снеговик и самопроверка с разбором семи ответов.

Для опытов используется окно 800×600 и радиус 50. Разобраны центры `(50, 300)`, `(750, 300)`, `(750, 550)`, частичный выход и невидимые положения `(-50, 300)`, `(850, 300)`, `(400, -50)`, `(400, 650)`. Объясняется различие координат центра и края, границы области и последнего пикселя. Отдельно оговорено округление растрового контура и возможность исчезновения возле угла раньше полного выхода за одну сторону.

`screen` объясняется как явно указанная поверхность: в игре могут быть разные поверхности для рисования, а в текущей программе одна — поверхность окна. Разные поверхности не приравниваются к нескольким окнам.

Практика предлагает написать снеговика из шести кругов: три белых шара, два черных глаза и оранжевый нос на голубом фоне. В задании есть требования, подсказка к подбору радиусов и расстояния между центрами, список проверок. Готовое решение ученику не выдается. Приложенный пользователем скриншот сохранен без изменений; дополнительно подготовлены пять схем с настоящими кругами Pygame, направляющими и подписями. Это учебные схемы, а не снимки системных окон.

## Файлы и проверка

- `content.py` — исходный урок; использует функции создания блоков из `data.pygame_intro.content`.
- `materials.md` — материал целиком с локальными изображениями.
- `lesson.json` — урок и степы в формате платформы.
- `build.py` — проверка схем и синтаксиса, экспорт, транзакционное добавление второго урока без изменения первого.
- `render.py` — повторная генерация пяти схем с Pygame и DejaVu Sans.
- `illustrations.py` — загрузка изображений штатным хранилищем приложения, проверка SHA-256 и добавление блоков `image`.
- `images.json` — привязки файлов к текущей базе; для другой базы создаются заново.

Из корня проекта:

```bash
.venv/bin/python -m data.pygame_drawing.build --check --export
```

Для повторной генерации схем нужен Python с Pygame:

```bash
SDL_VIDEODRIVER=dummy python -m data.pygame_drawing.render
```

В текущую базу материал уже загружен. Для повторной сверки после копирования каталога в контейнер:

```bash
docker compose cp data/pygame_drawing/. app:/app/data/pygame_drawing/
docker compose exec -T app python -m data.pygame_drawing.build --apply --course-id 3
```

Импортер требует существующий раздел с первым уроком и добавляет только второй урок. При совпадении ничего не меняет; при отличиях останавливается без перезаписи. Последующие уроки в разделе не препятствуют повторной сверке.

Для другой базы с уже установленным первым уроком сначала скопируй этот каталог **без `images.json`**, выполни импорт, затем привяжи изображения к полученному ID урока:

```bash
python -m data.pygame_drawing.illustrations --apply --lesson-id <ID>
```

Скопируй новый `images.json` из контейнера обратно и повтори экспорт. Скрипт иллюстраций допускает только исходное содержимое или точное совпадение с последним экспортом, не перезаписывает посторонние правки и повторно использует зарегистрированные файлы.

Проверены схемы всех 12 степов, синтаксис и исполнение всех 9 примеров с Pygame 2.6.1. Для полной программы проверены размер кадра, фон и белый круг; для 15 положений круга — границы рисования, частичная видимость и полное исчезновение. Отдельно собран рисунок по подсказке практики, проверены цвета глаз и носа и просмотрен результат. Исполнение проверялось с SDL dummy, без интерактивного системного окна.

После загрузки подтверждены доступность всех шести PNG по HTTP, точное сохранение первого урока и его 11 степов, а также повторный импорт без дубликатов.

Объяснения сверены с официальной документацией: [рисование кругов и отсечение по поверхности](https://www.pygame.org/docs/ref/draw.html#pygame.draw.circle), [поверхности](https://www.pygame.org/docs/ref/surface.html), [экранные координаты и поверхность окна](https://www.pygame.org/docs/ref/display.html).

В степ 5 «Центр, радиус и края круга» добавлена увеличенная схема `images/extreme-points.png`: центр (400, 300), радиус 50 и четыре крайние точки с общими формулами и конкретными координатами. Остальное содержимое степа и других степов при добавлении сверено и сохранено.
