# Четвертый урок разработки игр

«Клавиатура: реагируем на нажатия» установлен четвертым в раздел «Знакомство с Pygame» курса `python-gamedev-basics`: курс 3, раздел 9, урок 53, порядок 3. Первый степ — 394, домашнее задание — 402.

10 степов: первое событие KEYDOWN, определение клавиши, красный фон по R, четыре цвета, шаг круга вправо, движение влево, четыре направления, разбор ошибок, домашнее задание и самопроверка с ответами. Семь полных программ рассчитаны на локальный Python с Pygame. Удержание не настраивается: один KEYDOWN перемещает круг на 20 пикселей, между событиями круг стоит. FPS и непрерывное движение не вводятся.

Домашнее задание повторяет механику [предоставленного образца](https://docs.google.com/document/d/1PuOg9RebOj1CpykYvsXBTNkdL7VP6CCrlf3gSffIw68/edit): два симметричных красных квадрата, A выделяет левый синим и возвращает правому красный, D делает наоборот, пробел сбрасывает оба цвета. Заданы размеры и координаты; объяснен pygame.draw.rect. Готового решения в материалах ученика нет; условие оформлено обычным степом без автопроверки.

## Анимации

Четыре GIF созданы исполнением программ с настоящей очередью событий Pygame 2.6.1 и SDL dummy. Игровая область сохраняет размер 800×600, над ней добавлена поясняющая плашка высотой 80 пикселей. Она показывает клавишу, момент нажатия и отпускания; в демонстрациях круга также указаны координаты. В `right.gif` отдельно показано удержание без новых событий и без движения. Сброс положения при повторении этого GIF подписан.

- `colors.gif` — R, G, B и пробел меняют фон, цвет сохраняется после отпускания.
- `right.gif` — отдельные шаги вправо, удержание и пауза.
- `movement.gif` — замкнутый маршрут из 14 отдельных нажатий стрелок.
- `homework.gif` — ожидаемый результат ДЗ, в том числе повтор D и сбросы пробелом.

Каждый GIF меньше 140 КБ. Загружены штатным StorageService, вставлены как блоки image. `images.json` содержит ID файлов текущей базы, пути и SHA-256; для другой базы его необходимо создать заново.

## Проверка и воспроизведение

Из корня проекта, Python с Pygame и Pillow:

```bash
.venv/bin/python -m data.pygame_keyboard.render
.venv/bin/python -m data.pygame_keyboard.verify
.venv/bin/python -m data.pygame_keyboard.build --check --export
```

`verify.py` исполняет семь программ, отправляет настоящие KEYDOWN, KEYUP, MOUSEMOTION и QUIT. Проверяет сохранение выбранного цвета, отсутствие движения при паузе, обработку нескольких событий за кадр, очистку старого рисунка, направления и правила ДЗ. Для каждого кадра четырех GIF вся игровая область сравнивается побайтово с соответствующим кадром программы; дополнительно сверяются длительности кадров. Это проверка с SDL dummy; ручной ввод в системном окне не проверялся. Внешний вид подписей просмотрен на выбранных кадрах.

`build.py` проверяет схемы всех степов, синтаксис примеров, декодирование каждого кадра GIF и ограничение размера. Создает `lesson.json` для платформы и `materials.md` для чтения с локальными ссылками на GIF.

## Установка

Для текущей базы:

```bash
docker compose cp data/pygame_keyboard/. app:/app/data/pygame_keyboard/
docker compose exec -T app python -m data.pygame_keyboard.build --apply --course-id 3
```

Для другой базы с уже установленными первыми тремя уроками скопируй каталог **без images.json**, затем:

```bash
python -m data.pygame_keyboard.build --apply --course-id <ID курса>
python -m data.pygame_keyboard.illustrations --apply --lesson-id <ID нового урока>
python -m data.pygame_keyboard.build --check --export
```

При работе в Docker скопируй новый `images.json` из контейнера обратно в исходный каталог и обнови локальный экспорт. Импортер требует нужный slug курса и три предыдущих урока, добавляет только четвертый, а при повторном запуске сверяет материал без перезаписи. Посторонние отличия останавливают импорт. Скрипт иллюстраций проверяет содержимое урока, повторно использует файлы по имени с SHA-256, сверяет байты и удаляет новые загрузки при откате транзакции.

После установки подтверждены совпадение всех 10 степов с экспортом, четыре блока image, HTTP 200 и MIME image/gif для всех GIF, SHA-256 загруженных файлов и переход страницы урока на первый степ. Повторный импорт не создал дубликатов. Снимок до импорта подтвердил сохранение всех полей прежних трех уроков и 35 степов, включая текущие правки на сайте.

Объяснения сверены с официальной документацией: [события и их поля](https://www.pygame.org/docs/ref/event.html), [клавиши и выключенный по умолчанию повтор](https://www.pygame.org/docs/ref/key.html#pygame.key.set_repeat).
