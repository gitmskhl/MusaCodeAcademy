# Линейные алгоритмы

Минимум и максимум, суммы и счётчики, среднее по условию, поиск и серии, два лучших результата.

## Минимум и максимум

Храним лучший найденный результат и обновляем его при переборе.

### Как работает алгоритм

**Перед практикой**

Храним лучший найденный результат и обновляем его при переборе.

### Зачем нужен перебор

Представь, что ты записал температуру за несколько дней. Чтобы найти самый тёплый день, достаточно просмотреть каждое значение один раз и помнить самое большое из уже просмотренных.

Такой алгоритм называют **линейным**: если чисел станет вдвое больше, сравнений тоже станет примерно вдвое больше. Обычно это записывают как `O(n)`, где `n` — количество элементов. В этом разделе речь о времени работы при увеличении количества элементов.

### Как найти максимум

1. Возьми первое число за текущий максимум. Список должен быть непустым.

2. Перебери оставшиеся числа по индексам от `1` до `len(numbers) - 1`.

3. Если очередное число больше текущего максимума, замени максимум этим числом.

4. После цикла выведи результат. Для минимума всё так же, только сравнение будет `<`.

Второй пример запоминает ещё и индекс первого минимума. Индекс начинается с нуля, а номер дня для человека — с единицы. Строгое сравнение сохраняет первое вхождение при равенстве.

### Пример алгоритма 1

```python
numbers = [-6, -2, -9, -2]
maximum = numbers[0]
for i in range(1, len(numbers)):
    if numbers[i] > maximum:
        maximum = numbers[i]
print("Максимум:", maximum)
```

**Вывод программы:**

```text
Максимум: -2
```

### Пример алгоритма 2

```python
numbers = [8, 3, 6, 3]
minimum = numbers[0]
position = 0
for i in range(1, len(numbers)):
    if numbers[i] < minimum:
        minimum = numbers[i]
        position = i
print("Минимум:", minimum)
print("Номер:", position + 1)
```

**Вывод программы:**

```text
Минимум: 3
Номер: 2
```

### Проследим за максимумом

| Действие | Текущий максимум |
| --- | --- |
| Берём первое число −6 | −6 |
| Сравниваем −2 с −6 | −2 |
| Сравниваем −9 с −2 | −2 |
| Сравниваем −2 с −2 | −2 |

В конце `maximum` равен −2. В задаче про разницу температур можно в одном цикле обновлять и минимум, и максимум, а после цикла вычесть минимум из максимума.

В задачах ввод может сначала собираться в список обычным циклом с `append()`. Затем выполняется поиск. Два прохода тоже дают линейное время: количество действий растёт пропорционально `n`.

### Перед самостоятельной работой

Реализуй алгоритмы обычными циклами, без готовых `min()`, `max()`, `sum()`, `sorted()` и `sort()`. Эти функции удобны в работе, а здесь мы учимся писать сам перебор.

## Суммы и счётчики

Накапливаем сумму и считаем элементы, подходящие под условие.

### Как работает алгоритм

**Перед практикой**

Накапливаем сумму и считаем элементы, подходящие под условие.

### Два вида накопления

Чтобы найти **сумму**, начни с нуля и прибавляй очередное число. Чтобы найти **количество**, начни с нуля и прибавляй единицу, когда встретился нужный элемент.

Если нужны только некоторые числа, поставь обновление накопителя внутрь `if`. В первом примере считаются положительные числа и их сумма. Ноль под условие `number > 0` не подходит.

1. До цикла создай `total = 0` и `count = 0`.

2. Перебери числа. Если число подходит, прибавь его к сумме, а к счётчику прибавь 1.

3. После цикла выведи накопленные результаты.

Строку тоже можно перебирать по одному элементу — символу. Метод `letter.isupper()` проверяет, является ли символ заглавной буквой. Он работает и с русскими, и с латинскими буквами; цифры, пробелы и знаки препинания не считаются заглавными.

### Пример алгоритма 1

```python
numbers = [-4, 6, 0, 3]
total = 0
count = 0
for number in numbers:
    if number > 0:
        total += number
        count += 1
print("Сумма:", total)
print("Количество:", count)
```

**Вывод программы:**

```text
Сумма: 9
Количество: 2
```

### Пример алгоритма 2

```python
word = "Кот And 7!"
count = 0
for letter in word:
    if letter.isupper():
        count += 1
print("Заглавных:", count)
```

**Вывод программы:**

```text
Заглавных: 2
```

### Проследим за суммой и количеством

| Число | Подходит? | total | count |
| --- | --- | --- | --- |
| −4 | Нет | 0 | 0 |
| 6 | Да | 6 | 1 |
| 0 | Нет | 6 | 1 |
| 3 | Да | 9 | 2 |

Запись `total += number` означает то же, что `total = total + number`: к старой сумме прибавляется очередное число. В счётчике `count += 1` прибавляет одну найденную запись.

Каждое число или символ проверяется один раз. Время работы — `O(n)`.

**Частая ошибка**

Создавай накопитель до цикла. Если записать total = 0 внутри цикла, предыдущая сумма каждый раз будет теряться.

**Проверь себя**

Какими будут сумма и количество положительных чисел для [-2, 0, -1]? А для [2, 2, 5]?

## Среднее и отбор по условию

Объединяем сумму и счётчик, обрабатываем отсутствие подходящих чисел.

### Как работает алгоритм

**Перед практикой**

Объединяем сумму и счётчик, обрабатываем отсутствие подходящих чисел.

### Среднее только нужных чисел

Среднее арифметическое — сумма чисел, делённая на их количество. Если подходят только положительные числа, в сумму и количество должны попадать только они.

1. Создай сумму `total = 0` и счётчик `count = 0`.

2. В цикле проверяй условие. Для подходящего числа увеличивай оба накопителя.

3. Если `count > 0`, вычисли `total / count`. Оператор `/` даёт дробный результат: например, `6 / 2` — это `3.0`.

4. Если подходящих чисел нет, обработай этот случай отдельно. В первом примере выводится целый `0`.

Для отбора чётных чисел используй `number % 2 == 0`. Ноль тоже чётный. Чтобы считать числа выше среднего, сначала вычисли среднее всех чисел, а затем пройди список ещё раз.

### Пример алгоритма 1

```python
numbers = [-2, 5, 0, 7]
total = 0
count = 0
for number in numbers:
    if number > 0:
        total += number
        count += 1
if count > 0:
    print("Среднее положительных:", total / count)
else:
    print("Среднее положительных:", 0)
```

**Вывод программы:**

```text
Среднее положительных: 6.0
```

### Пример алгоритма 2

```python
numbers = [2, 4, 9]
total = 0
for number in numbers:
    total += number
average = total / len(numbers)
count = 0
for number in numbers:
    if number > average:
        count += 1
print("Выше среднего:", count)
```

**Вывод программы:**

```text
Выше среднего: 1
```

### Разберём первый пример

Числа −2 и 0 пропускаются. После числа 5 получаем `total = 5`, `count = 1`. После числа 7 получаем `total = 12`, `count = 2`. Среднее равно `12 / 2`, то есть `6.0`.

Во втором примере сумма равна 15, среднее — 5.0. При повторном проходе подходит только число 9. Два полных прохода — это примерно `2 * n` проверок, поэтому время по-прежнему `O(n)`.

### Если нужен минимум по условию

Нельзя брать первое число списка как минимум положительных: оно может быть отрицательным. Заведи флаг `found = False`. Первое подходящее число запомни отдельно, а последующие сравнивай с найденным минимумом.

**Частая ошибка**

Не дели сумму положительных на общее количество n. Если подходящих чисел нет, деление на их количество приведёт к ошибке.

## Поиск, соседи и серии

Ищем первое совпадение, сравниваем соседей и следим за длиной серии.

### Как работает алгоритм

**Перед практикой**

Ищем первое совпадение, сравниваем соседей и следим за длиной серии.

### Поиск первого совпадения

Перебирай индексы слева направо. Когда нашёл нужное число, запомни его номер и заверши поиск с `break`. Если совпадений нет, оставь заранее выбранный ответ `0`: настоящие номера начинаются с 1.

### Соседние элементы и серии

Соседи — элементы с индексами `i - 1` и `i`. Начинай сравнения с индекса 1, чтобы у текущего элемента был предыдущий.

**Серия одинаковых чисел** — непрерывный участок, где все числа равны. В списке `[4, 4, 7, 4]` максимальная длина серии равна 2, хотя число 4 встречается три раза.

1. Для непустого списка начни с `current = 1` и `best = 1`.

2. Если текущее число равно предыдущему, увеличь `current` на 1.

3. Если числа различаются, начни новую серию: `current = 1`.

4. После каждого сравнения обновляй `best`, если текущая серия длиннее.

Для пустого списка длина серии равна 0. В серии без уменьшений проверка другая: `numbers[i] >= numbers[i - 1]`. При равенстве такая серия продолжается.

### Пример алгоритма 1

```python
numbers = [6, 2, 6, 8]
target = 6
position = 0
for i in range(len(numbers)):
    if numbers[i] == target:
        position = i + 1
        break
print("Номер:", position)
```

**Вывод программы:**

```text
Номер: 1
```

### Пример алгоритма 2

```python
numbers = [4, 4, 7, 7, 7, 2]
current = 1
best = 1
for i in range(1, len(numbers)):
    if numbers[i] == numbers[i - 1]:
        current += 1
    else:
        current = 1
    if current > best:
        best = current
print("Самая длинная серия:", best)
```

**Вывод программы:**

```text
Самая длинная серия: 3
```

### Проследим за серией

| Просмотренный элемент | current | best |
| --- | --- | --- |
| Первый 4 | 1 | 1 |
| Второй 4 | 2 | 2 |
| Первый 7 | 1 | 2 |
| Второй 7 | 2 | 2 |
| Третий 7 | 3 | 3 |
| Число 2 | 1 | 3 |

`current` хранит длину серии, которая заканчивается прямо сейчас. `best` — лучшую длину за весь просмотр. Обновление внутри цикла позволяет учесть и серию, которая дошла до конца списка.

В поиске иногда удаётся остановиться раньше. Но в худшем случае нужно просмотреть все элементы — это `O(n)`. В задачах с соседями каждый соседний переход проверяется один раз.

**Частая ошибка**

При смене числа новая серия уже содержит один элемент, поэтому current становится 1. Не сбрасывай best вместе с current.

## Два лучших результата

Поддерживаем два максимума и различаем повторы значений.

### Как работает алгоритм

**Перед практикой**

Поддерживаем два максимума и различаем повторы значений.

### Второе по величине среди разных чисел

Представь соревнование: нужно узнать два лучших результата. Сортировать весь список необязательно. Достаточно хранить `first` — наибольшее число и `second` — второе по величине.

В первом примере все числа различны, их не меньше двух.

1. Возьми первые два числа и расположи их в переменных так, чтобы `first > second`.

2. Перебери оставшиеся числа.

3. Если число больше `first`, прежний `first` сдвинь в `second`, затем сохрани новое число в `first`.

4. Иначе, если число больше `second`, обнови только `second`.

### Если значения повторяются

Нужно внимательно читать, что считается вторым результатом. У двух участников могут быть одинаковые баллы: в `[9, 9, 4]` два лучших результата — 9 и 9. Но **второе различное значение** здесь равно 4.

Для второго различного значения можно сделать два прохода: сначала найти максимум, затем среди чисел строго меньше него найти наибольшее. Во втором примере флаг `found` показывает, встретился ли хотя бы один кандидат. Начальное значение `second = 0` используется только как заготовка и не участвует в сравнении до первого кандидата.

### Пример алгоритма 1

```python
numbers = [11, 4, 16, 8, 13]
first = numbers[0]
second = numbers[1]
if second > first:
    first, second = second, first
for i in range(2, len(numbers)):
    number = numbers[i]
    if number > first:
        second = first
        first = number
    elif number > second:
        second = number
print("Второе по величине:", second)
```

**Вывод программы:**

```text
Второе по величине: 13
```

### Пример алгоритма 2

```python
numbers = [9, 9, 4, 7]
maximum = numbers[0]
for number in numbers:
    if number > maximum:
        maximum = number
found = False
second = 0
for number in numbers:
    if number < maximum:
        if not found:
            second = number
            found = True
        elif number > second:
            second = number
if found:
    print("Второе различное:", second)
else:
    print("Второго различного нет")
```

**Вывод программы:**

```text
Второе различное: 7
```

### Проследим за двумя максимумами

| Действие | first | second |
| --- | --- | --- |
| Берём 11 и 4 | 11 | 4 |
| Приходит 16 | 16 | 11 |
| Приходит 8 | 16 | 11 |
| Приходит 13 | 16 | 13 |

При новом рекорде сначала сохрани старый максимум на втором месте, иначе он потеряется. Если нужны два результата с учётом повторов, тот же алгоритм с двумя переменными работает и при равенстве первых чисел.

Для поиска двух минимумов замени сравнения `>` на `<` и держи в `first` наименьшее число.

Один или два прохода дают время `O(n)`. Если список уже создан, для самих алгоритмов достаточно нескольких дополнительных переменных.

Не путай второй результат участника и второе различное значение. Не удаляй все повторы максимума, когда одинаковые баллы двух участников должны учитываться.
