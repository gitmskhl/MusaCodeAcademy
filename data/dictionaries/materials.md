# Словари

Ключи и значения, добавление и удаление записей, проверка наличия ключа, обычный перебор и две системы учета оценок.

## Что такое словарь

Пары «ключ — значение», создание словаря и получение значения по ключу.

### Ищем оценку по имени

Представь, что ты ведешь журнал. Нужно хранить имя ученика и его оценку. В списке мы обращались к элементу по номеру. А здесь хочется написать имя и сразу получить оценку.

Для этого есть **словарь**. Он хранит пары **ключ — значение**. В нашем примере ключ — имя, значение — оценка. Между ними стоит двоеточие, а пары разделяются запятыми. Весь словарь заключен в фигурные скобки.

Рассмотрим код ниже. **grades["Анна"]** означает: найди в словаре **grades** ключ **"Анна"** и возьми связанное с ним значение. Кавычки нужны, потому что имя — строка.

```python
grades = {"Анна": 5, "Муса": 4, "Иван": 3}
print(grades["Анна"])
print(grades["Муса"])
```

**Вывод программы:**

```text
5
4
```

### Ключ — это не номер места

Список **[5, 4]** хранит элементы под индексами 0 и 1. Словарь **{"Анна": 5, "Муса": 4}** хранит значения под ключами «Анна» и «Муса». Запись **grades[0]** не означает «первый ученик»: она ищет ключ **0**. Если такого ключа нет, возникнет **KeyError**.

Ключ можно хранить в переменной. **grades[name]** использует значение переменной **name**, а **grades["name"]** ищет буквальный ключ «name». Это разные обращения.

Значения могут повторяться: несколько учеников могут получить одинаковую оценку. Один ключ хранит только одно текущее значение. Пустой словарь создается как **{}**. В этом разделе ключами будут строки, иногда целые числа. Список ключом быть не может.

```python
grades = {"Анна": 5, "Муса": 5}
name = "Муса"
print(grades[name])
print(len(grades))
empty = {}
print(len(empty))
```

**Вывод программы:**

```text
5
2
0
```

### Как выполнять задания

В каждой задаче создавай новый словарь с данными из условия. Словари из предыдущих степов не сохраняются. Имена сравниваются точно: **Анна** и **анна** — разные ключи. Пробелы тоже имеют значение.

В примерах ввод и вывод показаны отдельно. Приглашения вроде **Введите имя** входят в вывод программы. В задачах этого урока запрашиваемые ключи гарантированно существуют: проверять их наличие научимся позже.

Не нужно запоминать готовые ответы. Даже если словарь небольшой, получай значения по ключам. Сначала идут короткие обращения, затем вычисления с найденными значениями.

## Добавляем, изменяем и удаляем записи

Присваивание по ключу, уникальность ключей и удаление через del.

### Одна запись — два действия

Чтобы добавить запись, напиши **dictionary[key] = value**. Если ключа еще нет, он появится. Если ключ уже есть, новое значение заменит старое.

В примере мы добавляем Ивана, а потом исправляем оценку Анны. Количество учеников увеличится только при добавлении нового имени. Двух отдельных записей с одинаковым ключом в словаре не бывает.

```python
grades = {"Анна": 5}
grades["Иван"] = 3
grades["Анна"] = 4
print(grades)
print(len(grades))
```

**Вывод программы:**

```text
{'Анна': 4, 'Иван': 3}
2
```

### Изменение на основе старого значения

Чтобы увеличить количество, сначала получаем старое значение, прибавляем нужное и записываем результат по тому же ключу. Правая часть присваивания вычисляется раньше, чем меняется значение слева.

Ключ должен существовать до чтения. Если ты напишешь **stock["альбом"] = stock["альбом"] + 1** для отсутствующего альбома, программа получит **KeyError**. В следующем уроке научимся проверять ключи.

```python
stock = {"ручка": 10}
stock["ручка"] = stock["ручка"] + 3
print(stock["ручка"])
```

**Вывод программы:**

```text
13
```

### Удаляем по ключу

Инструкция **del grades["Иван"]** удаляет всю пару: ключ и связанное значение. Она ничего не возвращает, поэтому не оборачивай ее в **print**.

Если ключа нет, **del** вызовет **KeyError**. Пока удаляем только те ключи, наличие которых гарантировано условием.

Словарь сохраняет порядок добавления ключей. Замена значения не перемещает ключ. Если удалить ключ и добавить его снова, он окажется в конце. Это пригодится при выводе словаря и переборе.

```python
grades = {"Анна": 5, "Иван": 3}
del grades["Иван"]
print(grades)
del grades["Анна"]
print(grades)
```

**Вывод программы:**

```text
{'Анна': 5}
{}
```

## Перебираем словарь обычным for

Цикл по ключам, получение значений через dictionary[key], отчеты и поиск максимума.

### Что попадает в переменную цикла

Напишем **for name in grades:**. На каждой итерации в **name** попадает очередной **ключ**. Чтобы получить оценку этого ученика, обращаемся к **grades[name]**.

Мы не используем **.items()**, **.values()** или **.keys()**: достаточно обычного **for key in dictionary**. Имя переменной выбираешь сам. Для журнала удобно **name**, для склада — **product**.

Порядок перебора совпадает с порядком добавления ключей. Сам по себе словарь не сортирует имена и оценки.

```python
grades = {"Анна": 5, "Муса": 4}
for name in grades:
    print(name, grades[name])
```

**Вывод программы:**

```text
Анна 5
Муса 4
```

### Отчет с условием и накоплением

Внутри перебора можно использовать знакомые условия и счетчики. В примере выводятся только отличники, а затем сумма всех оценок. Переменную суммы создаем до цикла.

Пустой словарь не выполнит тело цикла ни разу. Поэтому заранее подумай, что нужно вывести для пустого отчета.

```python
grades = {"Анна": 5, "Муса": 4, "Иван": 5}
total = 0
for name in grades:
    total = total + grades[name]
    if grades[name] == 5:
        print(name)
print("Сумма:", total)
```

**Вывод программы:**

```text
Анна
Иван
Сумма: 14
```

### Удаление во время перебора

Во время **for name in grades** нельзя добавлять или удалять ключи этого же словаря: программа может получить **RuntimeError**. Менять значения существующих ключей можно.


## Разбираем систему учета оценок

Имя — ключ, одна оценка — значение. Развиваем командную систему от записи до отчетов.

### Сначала договоримся о командах

Сделаем систему, которая работает, пока пользователь не введет **стоп**. Данные хранятся в **grades** и остаются между итерациями цикла. Поэтому **grades = {}** пишем **до while**, иначе журнал будет очищаться после каждой команды.

Для начала хватит трех команд. **записать** получает имя и оценку и записывает ее; повторное имя заменяет оценку. **оценка** показывает сохраненное значение или сообщает об отсутствии ученика. **стоп** выходит из цикла.

Имена непустые, оценки целые от 2 до 5. Команды сравниваем точно. Другие команды пока не обрабатываем.

### Собираем первую рабочую версию

Проследи за кодом. Сначала создается словарь. Затем каждый проход цикла читает одну команду. Только выбранная команда запрашивает дополнительные данные.

При команде **записать** сначала читаем имя, затем превращаем введенную оценку в число через **int**. Присваивание **grades[name] = grade** сохраняет ее для следующих команд. При **оценка** число уже не вводится: берем сохраненное значение по имени. Проверка **name in grades** защищает обращение к отсутствующему ключу.

После **стоп** выполняется **break**: имя или оценку программа больше не спрашивает. Затем выводится журнал. Запусти пример с входными данными ниже и посмотри, как запись становится доступна следующей команде.

```python
grades = {}
while True:
    print("Введите команду")
    command = input()
    if command == "стоп":
        break
    if command == "записать":
        print("Введите имя")
        name = input()
        print("Введите оценку")
        grade = int(input())
        grades[name] = grade
        print("Сохранено")
    if command == "оценка":
        print("Введите имя")
        name = input()
        if name in grades:
            print("Оценка:", grades[name])
        else:
            print("Нет ученика")
print("Журнал:", grades)
```

```text
оценка
Анна
стоп
```

## Список оценок по имени ученика

Список как значение словаря, два уровня обращения и вложенные циклы.

### Одной оценки уже мало

Раньше **grades["Анна"]** было числом. Теперь у ученика несколько оценок. Будем хранить **список** по каждому имени. Внешний словарь отвечает на вопрос «чьи данные?», внутренний список — «какие оценки?».

**journal["Анна"]** возвращает весь список. **journal["Анна"][0]** берет первую оценку из этого списка. Квадратные скобки выполняются по очереди: сначала поиск по имени, затем обращение по индексу.

У ученика может пока не быть оценок: значение **[]** допустимо. Такой ученик существует в журнале, но обращаться к его первой или последней оценке без проверки нельзя.

```python
journal = {"Анна": [5, 3], "Муса": []}
print(journal["Анна"])
print(journal["Анна"][0])
print(len(journal))
print(len(journal["Муса"]))
```

**Вывод программы:**

```text
[5, 3]
5
2
0
```

### Добавляем оценку и создаем ученика

**journal[name].append(grade)** добавляет оценку в существующий список. А **journal[name] = [grade]** заменит старый список новым и потеряет предыдущие оценки. Это разные действия.

При регистрации ученика создавай отдельный список выражением **journal[name] = []**. Не присваивай нескольким ученикам один заранее созданный список: тогда изменение через одно имя будет видно и через другое.

Проверь пример: у Анны появляется 4, а у Мусы список остается пустым, потому что это два разных списка.

```python
journal = {}
journal["Анна"] = []
journal["Муса"] = []
journal["Анна"].append(4)
print(journal)
```

**Вывод программы:**

```text
{'Анна': [4], 'Муса': []}
```

### Два разных удаления

**del journal[name]** удаляет ученика вместе со всеми оценками. **journal[name] = []** оставляет ученика, но очищает оценки.

Чтобы убрать последнюю оценку, сначала проверь существование ключа, затем непустоту списка. После этого можно записать **journal[name] = journal[name][:-1]**. Срез без последнего элемента мы уже проходили.

Чтобы удалить одну конкретную оценку, проверь **grade in journal[name]**, затем используй знакомый **remove**. Он удалит только первое совпадение.

```python
journal = {"Анна": [5, 3, 5], "Муса": [4]}
journal["Анна"].remove(5)
journal["Муса"] = []
print(journal)
```

**Вывод программы:**

```text
{'Анна': [3, 5], 'Муса': []}
```

### Внешний цикл — ученики, внутренний — оценки

Внешний **for name in journal** перебирает имена. Внутренний **for grade in journal[name]** перебирает оценки одного ученика. Никакие **.items()** и **.values()** не нужны.

В примере сумма создается внутри внешнего цикла: для каждого ученика считаем заново. Если бы мы создали ее только перед обоими циклами, суммы разных учеников начали бы смешиваться.

```python
journal = {"Анна": [5, 3], "Муса": [], "Иван": [4, 4]}
for name in journal:
    total = 0
    for grade in journal[name]:
        total = total + grade
    print(name, "-", len(journal[name]), "оценок, сумма", total)
```

**Вывод программы:**

```text
Анна - 2 оценок, сумма 8
Муса - 0 оценок, сумма 0
Иван - 2 оценок, сумма 8
```

## Разбираем расширенный электронный журнал

Команды регистрации, добавления и отмены оценок, удаления учеников и общие отчеты.

### План новой системы

Теперь **journal[name]** хранит список. Разделим регистрацию и добавление оценки: **ученик** создает пустой список, **оценка** добавляет одну оценку существующему ученику. Повторная регистрация не должна стирать прежние оценки.

Для команды **показать** различаем три случая: неизвестное имя, известное имя без оценок, известное имя с оценками. Для команды **отменить** убираем только последнюю оценку. Для **удалить** убираем всего ученика.

Сначала соберем работающую часть: регистрация и добавление оценок. Потом будем расширять ее в задачах. Все списки создаются отдельно внутри ветки регистрации.

### Пишем регистрацию и добавление

Обрати внимание: команда **оценка** всегда читает и имя, и оценку, даже если ученик неизвестен. Такой договор делает ввод предсказуемым. Неизвестный ученик автоматически не создается.

В ветке **ученик** проверяем ключ, а не длину списка. Уже зарегистрированный ученик с **[]** должен получить ответ **Уже есть**. В ветке **оценка** после проверки ключа вызываем **append** у списка **journal[name]**. Остальные списки при этом не меняются.

В примере повторная регистрация Анны отвечает **Уже есть**. Ее оценка 5 остается в списке. Если бы в этой ветке без проверки выполнялось **journal[name] = []**, оценка потерялась бы.

```python
journal = {}
while True:
    print("Введите команду")
    command = input()
    if command == "стоп":
        break
    if command == "ученик":
        print("Введите имя")
        name = input()
        if name in journal:
            print("Уже есть")
        else:
            journal[name] = []
            print("Добавлен")
    if command == "оценка":
        print("Введите имя")
        name = input()
        print("Введите оценку")
        grade = int(input())
        if name in journal:
            journal[name].append(grade)
            print("Добавлена")
        else:
            print("Нет ученика")
print("Журнал:", journal)
```

**Входные данные примера:**

```text
ученик
Анна
оценка
Анна
5
ученик
Анна
стоп
```

**Вывод программы:**

```text
Введите команду
Введите имя
Добавлен
Введите команду
Введите имя
Введите оценку
Добавлена
Введите команду
Введите имя
Уже есть
Введите команду
Журнал: {'Анна': [5]}
```

### Как устроить отчет

Отчет строится двумя циклами: по ученикам, затем по их оценкам. Если нужна общая сумма, создай ее до внешнего цикла. Если нужна сумма отдельного ученика, создавай внутри внешнего цикла.

Не путай **len(journal)** — количество учеников — с количеством всех оценок. Для общего количества оценок прибавляй **len(journal[name])** для каждого имени. Ученики с пустыми списками входят в число учеников и дают 0 оценок.

В заданиях собираем систему по частям: добавляем показ списка, отмену последней оценки, удаление ученика и отчеты. Финальная задача объединяет все команды. Проверяй последовательности команд, особенно повторную регистрацию и восстановление удаленного ученика.
