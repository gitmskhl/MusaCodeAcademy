# Третий урок разработки игр

«Движение: оживляем круг» добавлен третьим в раздел «Знакомство с Pygame» курса `python-gamedev-basics` (курс 3, раздел 9, урок 52, порядок 2, первый степ 381).

13 степов: 12 с объяснениями и один с условием самостоятельной работы «Практика: прыгающий круг» (степ 393). Условие оформлено как материал степа, без автопроверки и готового решения. Окно 800×600, черный фон, зеленый круг радиуса 20. Последовательность: повторная отрисовка → переменная x без изменения → x += 1 → x += 0.1 → перенос справа налево → движение влево → переменная y и движение вниз → вверх → диагонали → направления и наклон → горизонтальный отскок → след без очистки.

Каждый степ содержит полную исполнимую программу. Начальные значения стоят перед игровым циклом; изменение координат, условия, заливка и рисование — внутри, отдельно от обработки событий. Различаются границы полного выхода (-20, 820; -20, 620) и касания изнутри (20, 780). Подчеркивается, что дробная часть должна накапливаться и скорость зависит от числа проходов. FPS и регулирование времени не вводятся.

## GIF

12 анимаций созданы исполнением тех же программ с Pygame 2.6.1 и SDL dummy. Область окна сохраняет размер 800×600. В 11 демонстрациях над ней добавлена плашка с координатами и номером прохода. Образец задания jump.gif показывает только окно без плашки: x = 400, y от 200 до 400, начальный y = 300, первое направление вверх. Все 200 кадров проверены: круг без следа, шаг между кадрами и на стыке повторения — 2 пикселя. В GIF выбраны отдельные кадры, темп служит иллюстрацией. В сравнении шагов 1 и 0.1 одинаковы число проходов (600), интервал выборки (5) и длительность кадра GIF (50 мс). Поэтому расстояния действительно различаются в десять раз. Повтор GIF начинается с начального состояния программы.

Файлы меньше лимита 10 МиБ и загружаются штатным `StorageService` без изменения байтов. `images.json` содержит привязки к текущей БД и SHA-256; для другой БД его нужно создать заново.

## Воспроизведение

Из корня проекта (локальному Python нужны Pygame и Pillow):

```bash
.venv/bin/python -m data.pygame_movement.render
.venv/bin/python -m data.pygame_movement.verify
.venv/bin/python -m data.pygame_movement.build --check --export
```

Для установки в существующий курс с первыми двумя уроками:

```bash
docker compose cp data/pygame_movement/. app:/app/data/pygame_movement/
docker compose exec -T app python -m data.pygame_movement.build --apply --course-id 3
# ID нового урока выводится импортером:
docker compose exec -T app python -m data.pygame_movement.illustrations --apply --lesson-id <ID>
docker compose cp app:/app/data/pygame_movement/images.json data/pygame_movement/images.json
.venv/bin/python -m data.pygame_movement.build --check --export
```

При первом переносе в другую базу каталог копируется без `images.json`. При повторной сверке текущей базы нужен актуальный манифест. Импортер добавляет только третий урок, при совпадении ничего не меняет, при посторонних отличиях останавливается без перезаписи. Файлы повторно используются по имени с SHA-256, сверяются по содержимому; при сбое транзакции новые загрузки удаляются.

`verify.py` проверяет исполнение 12 примеров, неподвижность x без изменения, накопление дробного шага, перенос по четырем сторонам, диагонали, обе смены направления при отскоке, сохранение следа и очистку фона. `build.py` проверяет схемы степов, синтаксис программ, все кадры GIF и ограничения размера.

Дробные координаты центра поддерживаются [официальным pygame.draw.circle](https://www.pygame.org/docs/ref/draw.html#pygame.draw.circle).

После установки подтверждены точное совпадение 13 степов с экспортом, 12 блоков image, отсутствие объектов автопроверяемых заданий, HTTP 200 и MIME image/gif для всех загрузок с проверкой SHA-256. Все 22 существовавших степа первых двух уроков сверены со снимком до импорта и сохранены без изменений. Повторный импорт не создает дубликатов.

## Добавление практики в ранее установленный урок

Если в базе уже есть 12 исходных степов, после копирования обновленных файлов выполни:

```bash
docker compose exec -T app python -m data.pygame_movement.practice --apply --lesson-id 52
docker compose cp app:/app/data/pygame_movement/images.json data/pygame_movement/images.json
.venv/bin/python -m data.pygame_movement.build --check --export
```

Скрипт транзакционно загружает GIF и добавляет только степ 13, сверяет текущие материалы и допускает повторный запуск без дубликатов. После добавления сохранены без изменений все 34 ранее существовавших степа первых трех уроков, включая актуальную правку первого степа на сайте.
