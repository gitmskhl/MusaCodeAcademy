# Понятные условия задач

Выбранные задачи курса «Python. Основы», начиная с циклов. В терминальных примерах строки с `>` — ввод пользователя, остальные — вывод программы.

## Циклы · Зачем нужны циклы?

### Задание 1: сколько раз ввели python

Степ 49.

Пользователь вводит 5 слов, каждое с новой строки. Посчитай, сколько раз он ввёл слово `python`.

Считай только точное совпадение: `Python`, `python3` и `python ` с пробелом не подходят.

Перед каждым вводом выводи `Введите слово`. После пяти слов выведи `Слов python: <количество>`.

Используй цикл `for` и счётчик.

Пример выполнения:

```text
Введите слово
> python
Введите слово
> cat
Введите слово
> python
Введите слово
> Python
Введите слово
> dog
Слов python: 2
```

Еще пример:

```text
Введите слово
> cat
Введите слово
> dog
Введите слово
> java
Введите слово
> hello
Введите слово
> code
Слов python: 0
```
